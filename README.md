# Delta School Turbat

Frontend-only school website for **Delta School Turbat**.

## Current version

This first version contains only the public frontend website:

- Home section
- About section
- Academics section
- Admissions form UI
- Contact section
- Admin preview UI

> No backend, database, authentication, or real student record storage is connected yet.

## Local development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the website locally:

```text
http://localhost:3000
```

## Important privacy note

Do not enter real student information until a secure backend/database is added.
